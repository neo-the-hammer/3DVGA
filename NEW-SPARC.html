SPARC Method Guide

SPARC stands for Speech-Prosodic Anchor–Referent Coupling. It adds two things to SPOT, an audio-only 3D visual grounder: a clock that follows the speaker’s pauses, and a score that judges pairs of objects, a target and the anchor it is described against. Both are switched off by default, so the default model is still SPOT.

The gapWhat SPOT leaves on the table

1 · The relation never meets its object

SPOT turns the spoken relation into a bias on how proposals attend to each other, then scores every proposal alone. “The chair next to the table” is a statement about a pair. Among nine chairs, only the pair tells them apart.

2 · Time is linear

A slot’s time prior is a Gaussian over position in the clip. A phrase is not a fixed fraction of a clip, and prosody is used only to tweak features, never to set structure.

3 · No anchor role

Only a referent and a relation are elected. The thing the relation points at has no representation of its own.

Big pictureWhere the two additions sit

Addition 1The prosodic clock

The speaker’s pauses and phrase breaks tell you where one piece of the description ends and the next begins. Prosody channel 5, boundary strength, is large at those places. The clock turns it into a time axis that runs faster across a boundary, so that a slot’s Gaussian covers a phrase and not a stretch of seconds.

z_t = ( b_t − mean(b) ) / std(b) b = boundary strength, per utterance w_t = 0.25 + sigmoid( g · z_t + c ) learned gain g and bias c, zero on padding clock = ( Σ_(s<t) w_s ) / ( Σ_s w_s ) exclusive running sum, lands in [0, 1) pos_t = (1 − m) · t / T_real + m · clock_t m = sigmoid(clock_mix), starts at 0.018

Ordered slots

With the clock on, the slot centres are an increasing sequence: μk = Σi≤k softplus(gapi). They are initialised at the same evenly spaced 0.15 … 0.85 as before, but can no longer swap places, so the six slots are consecutive segments of the utterance. Slot 1 can drift toward “the brown chair”, slot 5 toward “the table”.

Addition 2aThree elected roles

Addition 2bPair grounding with a latent anchor

ScanRefer has no anchor labels and this model reads no text. So the anchor is a hidden variable. With 256 proposals the full 256 × 256 table of (target i, anchor j) pairs is small enough to sum over exactly, which removes any need for sampling or a hard guess.

u_i = s · cos( W_r·referent , W_r′·V_i ) how well proposal i matches the referent phrase v_j = s · cos( W_a·anchor , W_a′·V_j ) how well proposal j matches the anchor phrase g_ij = 5·tanh( Σ_k w_k(relation) · φ_k(geom_ij) / 5 ) relation-conditioned pair potential s_ij = u_i + v_j + g_ij score_i = u_i + logsumexp( { v_j + g_ij : j ≠ i, j real } ∪ { null } )

The relation decides how a pair is judged

Addition 2cThe null anchor

Not every description has an anchor: “the chair in the corner” names none. A null column is added to the table, with logit n = b₀ + b₁ · (1 − presence). Presence is K · Σk aanchor,k · massk. It is about 1 when the elected anchor slot won an average share of the utterance, and about 0 when it won nothing, so “no anchor was spoken” reaches the score through the slot mass SPOT already computes.

Putting it togetherJoining the SPOT score

confidence_i = SPOT score_i + gain · log_softmax_i( u_i + logsumexp_j(…) ) gain starts at 0 answer = argmax_i confidence_i (non-objects masked with −10⁴)

Because the gain starts at zero, step one is exactly SPOT. A zero gain also blocks the gradient to every other parameter in the grounder, so the first thing training has to do is move the gain. If it stays near zero in the first epoch, start it at 0.1. The same “start as the old thing” rule is used elsewhere: the clock mix starts at sigmoid(−4), which is the same trick as RSK’s blend.

No new loss

The anchor is trained only through the existing grounding loss. The only change to the objective is that role separation now covers every pair of roles.

Audio only

No transcript, no text teacher, no anchor labels. The training signal for the anchor is whether the pair helps find the right target.

Cost

The pair table is 64 × 256 × 257 numbers per batch, about 17 MB for one copy in float32. A few copies are alive at once, which is small next to the detector.

Predictions that can fail

  • Where the gain lands. sparc should beat spot by more than the seed spread, mostly on the Multiple subset. A gain on Unique instead would mean the mechanism is not the claimed one.
  • Null mass. The null probability should be high for utterances with no relation. An analysis-only comparison against the existing parse of “neighbors” (never used in training) can test this.
  • Hard anchor. sparc-hardanchor should not beat sparc. If it does, exact marginalisation is not what helps.
